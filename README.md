# RenegadeRocks' Claude Code mods

Four mods for Claude Code. Install any of them, or all four.

| Mod | What it does |
|---|---|
| [context-bar](context-bar) | A card above your prompt: how full the context is, your 5-hour and weekly limits with a Limit Coach, cache savings and API cost, the model and effort, a quote, and Rocky, a cat or dog who grows with your context. |
| [soundtrack](soundtrack) | Soft sounds for what Claude is doing: a rising chord when it starts, a quiet tick while tools run, a chime when it's done. |
| [project-colors](project-colors) | Every project gets its own prompt-bar colour and session name, and learns from your own `/color` and `/rename`. |
| [project-links](project-links) | A Links pane on the right with your project's artifacts and important links, read from `dashboard/links.json`; `/links` prints them. |

## Install

In Claude Code, type one line per mod:

```
/plugin install context-bar --marketplace RenegadeRocks/claude-mods
/plugin install soundtrack --marketplace RenegadeRocks/claude-mods
/plugin install project-colors --marketplace RenegadeRocks/claude-mods
/plugin install project-links --marketplace RenegadeRocks/claude-mods
```

The first time, press `y` to add the marketplace. Pick the **user** scope so a mod shows in every session. Each one works right away.

To turn one off later: `/plugin`, then **Installed**, then the mod, then disable or uninstall.
